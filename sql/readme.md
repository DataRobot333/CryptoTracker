# SQL Analytics Layer

This folder contains analytical SQL queries built on top of a cryptocurrency time-series database.

The queries are grouped into four categories:

- Market Overview: snapshot-level analysis and latest pricing
- Time-Series Analysis: daily/weekly aggregated trends
- Performance Metrics: dominance, ranking, and comparative analysis
- OHLC Reconstruction: candlestick-style market modeling from snapshots

These queries form the analytical layer of a real-time cryptocurrency data platform.
