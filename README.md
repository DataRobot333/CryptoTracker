# CryptoTracker

Automated cryptocurrency data collection and analytics pipeline built on Raspberry Pi using Python and PostgreSQL.

## Overview

This project collects cryptocurrency market data from external APIs and stores it in PostgreSQL for analysis and visualization.

The goal is to build a complete end-to-end data analytics platform using real-world crypto market data.

## Current Features

* Automated data collection
* PostgreSQL database storage
* Historical price tracking
* Environment variable management using `.env`
* GitHub version control
* Raspberry Pi deployment

## Technology Stack

* Python
* PostgreSQL
* SQL
* Linux (Raspberry Pi)
* Git & GitHub

## Project Roadmap

Raspberry Pi
→ Data Collection
→ PostgreSQL
→ SQL Analytics
→ Dashboard
→ Trading Signals
→ Telegram Alerts

## Installation

```bash
pip install -r requirements.txt
python collector.py
```
